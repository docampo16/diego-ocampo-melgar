CONTEXTO

Detectar antes de que la ocupación se consolide

Los asentamientos informales dentro o cerca de franjas de transmisión eléctrica generan riesgos de seguridad, acceso, incendios y exposición de personas a infraestructura crítica. Cuando la ocupación ya está consolidada, la respuesta puede implicar negociaciones, regularización o relocalización con costos crecientes.

ANÁLISIS

Redes neuronales para distinguir cambios relevantes

El núcleo del sistema se basó en modelos de redes neuronales entrenados con imágenes satelitales para reconocer asentamientos, construcciones emergentes y expansión de ocupaciones. El desarrollo incluyó preparación y etiquetado de datos, entrenamiento, evaluación de desempeño y ajuste de criterios espaciales para reducir falsos positivos asociados a caminos, infraestructura existente, suelos desnudos y variaciones normales del paisaje.

ANÁLISIS

Conectar el modelo con la lógica operacional

Las detecciones se analizaron respecto de franjas de seguridad y activos eléctricos para priorizar cambios según ubicación y proximidad a infraestructura crítica. Cada nueva observación podía compararse con estados anteriores para reconocer aparición, persistencia o crecimiento.

ANÁLISIS

Convertir imágenes en una cola de trabajo

La plataforma se concibió como un sistema de detección, seguimiento y alerta. El objetivo final fue que los equipos no tuvieran que revisar manualmente extensas superficies, sino recibir evidencia espacial de dónde mirar y cuándo intervenir. La misma lógica es transferible a invasión de servidumbres, nuevas construcciones, pérdida de cobertura y otras actividades no autorizadas.

VALOR DEL PROYECTO

Qué demuestra este proyecto

Capacidad para entrenar modelos de deep learning y convertir sus detecciones en un sistema recurrente de vigilancia territorial conectado con infraestructura crítica.

En monitoreo operacional, el rendimiento del modelo importa, pero el valor aparece cuando la detección se convierte en una alerta priorizada y verificable para el equipo que debe actuar.
